# 📚 BookNest

A full-featured online bookstore built with **React** and **Tailwind CSS**.

## 🚀 Live Demo

[View BookNest Live](https://react-from-zero-to-hero-complete-bo.vercel.app/)

## ✨ Features

- 📚 Browse programming books from Open Library API
- 🔍 Search books by title
- 🛒 Add to cart / Remove from cart
- 💾 Cart persists after refresh (localStorage)
- 👤 Mock authentication (login/logout)
- 📄 Protected routes (cart page)
- 🧭 Multi-page routing (Home, Book Details, Cart, 404)
- 🎨 Responsive design with Tailwind CSS
- ⏳ Loading spinner & error handling
- 🔄 Debounced search

## 🛠️ Built With

- React 19
- Tailwind CSS 4
- React Router
- Context API + useReducer
- Vite
- Open Library API

## 🏗️ Installation

```bash
git clone https://github.com/oladiiposaheed/React-from-Zero-to-Hero---Complete-Bootcamp-with-BookNest-project.git
cd booknest
npm install
npm run dev
```
