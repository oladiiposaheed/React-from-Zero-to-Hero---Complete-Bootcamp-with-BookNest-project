# 🚀 React Bootcamp — From Zero to Hero

A complete React learning journey from fundamentals to deployment.

## 📚 BookNest — The Main Project

A full-featured online bookstore built throughout this bootcamp.

### 🔗 [View BookNest Live](https://react-from-zero-to-hero-complete-bo.vercel.app/)

### 🛠️ Tech Stack

- React 19
- Tailwind CSS 4
- React Router
- Context API + useReducer
- Open Library API
- Vite

## 📂 What's Inside

| Folder                         | Description                |
| ------------------------------ | -------------------------- |
| `booknest/`                    | The main React application |
| `chapter-01/` to `chapter-15/` | Lessons and mini-projects  |
| `chapter-11-authentication/`   | Auth lessons               |
| `chapter-12-testing/`          | Testing with Vitest        |
| `chapter-13-typescript/`       | TypeScript basics          |
| `chapter-14-nextjs/`           | Next.js intro              |

## 🏗️ Run Locally

```bash
cd booknest
npm install
npm run dev
```
