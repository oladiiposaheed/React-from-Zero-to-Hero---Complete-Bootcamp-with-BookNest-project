# Task 1: What is Testing?

Testing = code that checks if your app works.

TYPES:

- Unit Test: Tests one component
- Integration Test: Tests multiple components together
- E2E Test: Tests the whole app

KEY FUNCTIONS:

- test() — defines a test
- render() — puts component on screen
- expect() — checks a condition
- screen.getByText() — finds text on screen
- toBeInTheDocument() — checks if element exists
