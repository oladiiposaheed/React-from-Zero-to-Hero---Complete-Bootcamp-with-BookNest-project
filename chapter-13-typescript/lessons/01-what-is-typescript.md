# Task 1: What is TypeScript?

TypeScript = JavaScript + types.

PROBLEM WITH JAVASCRIPT:

- No type checking
- Errors only at runtime
- Bugs from wrong data types

TYPESCRIPT SOLUTION:

- Type checking while you code
- Red squiggly lines = errors before running
- Catches mistakes early

KEY SYNTAX:

- : string → must be text
- : number → must be a number
- : boolean → must be true/false
