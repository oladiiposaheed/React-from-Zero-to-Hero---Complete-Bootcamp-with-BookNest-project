# Task 1: What is Next.js?

Next.js = React framework with superpowers.

ADDS TO REACT:

- Server-side rendering (faster, better SEO)
- File-based routing (no React Router needed)
- API routes (backend in same project)
- Image optimization
- Built-in deployment

KEY DIFFERENCE:
React: Browser builds the page
Next.js: Server sends pre-built page → faster
